## 📅 Day-wise Progress

### Day 01 — JavaScript Functions Basics
- Wrote basic functions to **add**, **subtract**, and **multiply** two numbers.
- Practiced calling functions and printing results with `console.log`.
- File: `day 01/cal.js`

### Day 02 — Function Types in JavaScript
- Learned different ways to write functions in JS:
  - Arrow functions
  - Function expressions
  - Function declarations
- File: `day 02/function.html`

### Day 03 — Array Methods: `filter()` & `reduce()`
- Used `filter()` to get even numbers from an array, then `reduce()` to sum them.
- Used `filter()` to get students scoring above 50 marks from an array of objects.
- Files: `day 03/map.html`, `day 03/Filter.html`

### Day 04 — Array `map()` & Promises
- Used `map()` to double every element in an array.
- Learned **Promises**: `resolve`, `reject`, `.then()`, `.catch()`.
- Practiced a real-world style promise example (pass/fail marks scenario) with `setTimeout`.
- Files: `day 04/map.html`, `day 04/promis.html`, `day 04/activity.html`

### Day 05 — Fetch API
- Learned how to fetch data from an API using `async/await` and the `fetch()` function.
- Used `https://jsonplaceholder.typicode.com/posts` as a test API.
- File: `day 05/fatchdata.html`

### Day 06 — Node.js Modules & REST Basics
- Learned the difference between **CommonJS** (`require`/`module.exports`) and **ES Modules** (`import`/`export`).
- Created reusable `add`, `sub`, `mal` functions in a separate file and imported them.
- Practiced REST API methods (GET, POST, PATCH, PUT, DELETE) using a `.rest` file.
- Set up a basic Node.js project with `package.json` and `express`.
- Files: `day 06/1st-node/index.js`, `day 06/1st-node/change.js`, `day 06/test.rest`

### Day 07 — Node.js Built-in Modules (`os`, `fs`)
- Explored the built-in **`os`** module: `uptime()`, `hostname()`, `version()`, `machine()`.
- Learned the **`fs`** (File System) module:
  - Reading files synchronously (`readFileSync`) and asynchronously (`readFile`).
  - Appending data to a file (`appendFileSync`).
- File: `day 07/index.js`

### Day 08 — Creating a Basic HTTP Server
- Learned to create a raw Node.js server using the built-in **`http`** module.
- Handled different routes (`/home`, `/contact`) and returned custom responses for unmatched routes.
- Practiced running the server on different ports (3000, 5001).
- File: `day 08/index.js`
